GitHub connection

Publishing uses a fine-grained personal access token. It is kept in this browser on this computer only — never in the draft, an export or the repository — and is only ever sent to GitHub.

A token is saved on this computer.

Making a token
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → ProcessHub.
  3. Permissions: Contents → Read and write. Nothing else.
  4. An expiry of 90 days is sensible. When it runs out, make a new one and paste it here.
